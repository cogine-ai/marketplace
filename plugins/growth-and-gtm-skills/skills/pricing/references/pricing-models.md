# Pricing Models

Start from the value metric — the unit associated with customer value — and choose how to charge. Packaging and price points are separate decisions.

| Model | Structure | Fit and constraint |
| --- | --- | --- |
| Flat rate | One price for a defined offer | Simple needs; check cost and value differences across customers |
| Usage | Charge for metered consumption | Consumption tracks value; make units and spend expectations understandable |
| Tier | Packages at different prices | Distinct needs or budgets justify the packages |
| User / seat | Charge per person | Additional users create additional value; avoid penalizing necessary participation |
| Feature | Charge for capabilities | Features distinguish customer needs without obscuring the core promise |
| Credit | Prepaid units consumed by actions | Variable or bursty usage; explain conversion, limits, and expiry terms |
| Outcome | Charge for an agreed result | The result is measurable, attributable, and accepted by buyer and seller |
| Hybrid | Combine a primary model with another | A real segment is poorly served by one model; justify the added complexity |

Common combinations include platform fee plus usage, tiers plus seats, and seats plus credits. Pick the primary model from observed value and add a second only for an identified need. State what users pay for, how they can predict the bill, and how the offer fits existing commitments.

Treat value-to-price ratios, discount behavior, and retention claims as hypotheses requiring evidence from the relevant segment. They do not establish a universal price floor or justify an automatic price increase.
