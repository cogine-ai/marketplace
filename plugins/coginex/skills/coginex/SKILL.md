# CogineX

通过宿主已连接的 CogineX 工具完成用户请求。工具名称可能带宿主或插件前缀；调用以当前工具描述、schema 和结果为准，宿主支持工具搜索时按本次需要发现工具。

按请求从宿主当前已启用、可发现的命名空间技能中选择场景指导，例如 `coginex:tasks`。使用宿主实际显示的名称与启用状态；下表链接仅供定位，不是绕过技能开关加载文件的指令。

| 用户要完成的事 | 技能 |
| --- | --- |
| 登录、查看当前账户、重连、切换账户或退出 | [setup](../setup/SKILL.md) |
| 查任务、创建和推进任务、改属性、写任务更新 | [tasks](../tasks/SKILL.md) |
| 找资料、读写文档、追溯讨论和任务历史 | [knowledge](../knowledge/SKILL.md) |
| 频道沟通、日历、提醒、通知、Bot、CRM | [collaboration](../collaboration/SKILL.md) |

不要把已关闭或未发现的场景技能当作参考文件自动读取，也不要因链接存在就视为已启用。技能开关控制场景指导的加载，不关闭 CogineX MCP 工具；仍可直接使用宿主当前提供的工具完成请求。

单个工具即可完成的请求可以直接执行。跨场景工作按结果接力 ID，保留用户给定的目标、可见性和已有授权，不为每一步重新索要确认。

这些技能提供场景指导，工具范围由当前 CogineX 服务和账户权限决定。需要了解完整工具分组或服务端缺口时，读取 [能力清单](../../docs/capabilities.md)；不要把文档快照当作当前连接的实际状态。
