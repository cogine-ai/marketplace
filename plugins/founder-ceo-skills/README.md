# Founder/CEO

Founder/CEO is a focused, cross-platform toolkit for Codex and Claude Code. It
covers founder judgment, product-market fit, strategic power, operating
cadence, organization, capital, fundraising, and stakeholder communication.

## Included Skills

### Founder judgment and PMF — 4

- `founder-office-hours`
- `measuring-pmf`
- `high-stakes-decisions`
- `planmode-ceo`

### Strategy and operating system — 5

- `competitive-strategy`
- `seven-powers`
- `planning-cadence`
- `risk-assessment`
- `ceo-advisor`

### Organization and leadership — 3

- `org-design`
- `founding-exec-team`
- `leading-org-change`

### Capital and stakeholder communication — 4

- `startup-finance`
- `fundraising`
- `investor-materials`
- `gtm-board-and-investor-communication`

## Design Choices

- `planmode-ceo` is copied unchanged.
- `ceo-advisor` is reserved for an explicit request for “CEO 综合建议” or
  another broad, cross-domain CEO review; specialized skills handle narrower
  questions.
- `competitive-strategy` and `seven-powers` intentionally overlap:
  the first supports broad competitive choices, while the second provides a
  rigorous durable-power audit.
- `startup-finance` is a short, tool-neutral workflow with correct cash,
  burn, runway, scenario, and unit-economics handling.
- No skill requires a specific CRM, finance system, workspace connector, or
  agent platform.
